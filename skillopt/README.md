# SkillOpt Assets

This directory stores local SkillOpt assets used to optimize `SKILL.md`.

Structure:

- `configs/skillqa/`: training configs for the easy-query `skillqa` benchmark
- `data/`: curated dataset and train/val/test split files
- `notes/`: experiment notes worth keeping in git

Excluded from git:

- `runs/`: training outputs and rollout artifacts
- `notes/tmp_easy_query_skill.md`: temporary scratch skill snapshots

These files are maintenance assets for this repository. They are not part of
the installed Codex skill surface.
